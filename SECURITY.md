# Security policy

> Placeholder: the supported-versions table is added at the first release.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/fereshteh-dev/spring-inspector/security/advisories/new)
rather than public issues.

Spring Inspector treats the code it inspects as untrusted data: it never executes it and never
follows instructions found inside it. Reports that break that guarantee are especially welcome.
